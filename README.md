# ⚖️ 裁判文书本地脱敏工具

> 纯前端 · 零依赖 · 数据不出本地

一个专为法律从业者设计的裁判文书敏感信息脱敏工具。所有处理均在浏览器本地完成，**不会上传或发送任何数据**。适用于公开、共享或归档裁判文书前快速隐藏当事人、审判人员、案号等个人信息。

---

## ✨ 功能特点

- 🔒 **本地处理** – 无需网络，数据绝不离开您的设备。
- 🎭 **两种脱敏模式**：
  - **替换式** – 将敏感词替换为“当事人1”“审判人员1”等可追踪标识。
  - **遮蔽式** – 用黑色块覆盖敏感内容，视觉效果更直观。
- 🧩 **可自定义字段** – 自由启用/禁用 16 种敏感信息类别。
- ↩️ **逐项恢复** – 对照表中可对任意实体单独“取消替换”或“重新替换”，便于人工复核。
- 📥 **导出对照表** – 支持复制或下载 CSV 格式的替换对照表，方便备案或二次审核。
- 📊 **清晰界面** – 左右分栏对比，实时统计字数与替换数量。

## 📋 脱敏字段一览

| 字段类别 | 说明 |
|----------|------|
| 👤 当事人姓名 | 公诉机关、原告、被告、上诉人、被上诉人、申请人等称谓后的姓名 |
| 👨‍⚖️ 审判人员姓名 | 审判长、审判员、书记员、执行员等 |
| 📎 法定代表人 / 委托代理人 | 法定代表人、负责人、委托诉讼代理人等 |
| 🏛️ 法院名称 | 各级人民法院及专门法院 |
| 🔢 案号 | 新旧式案号格式 |
| 🎂 出生日期 | 如“1990年1月1日出生” |
| 🪪 身份证号 | 18位（含末位X） |
| 🏢 统一社会信用代码 | 18位信用代码及组织机构代码 |
| 📞 手机 / 电话号码 | 手机号及带标签的电话号码 |
| 💳 银行卡 / 账号 | 16~19位连续数字 |
| ✉️ 电子邮箱 | 标准邮箱格式 |
| 📍 住址 / 详细地址 | 含省市区街道门牌号 |
| 📅 具体日期 | 如“2025年12月31日” |
| 💰 金额数字 | 含人民币符号及元单位 |
| 大写金额 | 大写数字金额 |
| 🏢 公司 / 单位名称 | 各类企业、事务所等 |
| 🚗 车牌号 | 国内标准车牌 |

> 💡 您可以在界面中自由勾选需要启用的字段，未勾选的将不会被匹配。

## 🚀 使用方法

1. 打开 `index.html` 文件（推荐使用 Chrome / Edge / Firefox 等现代浏览器）。
2. 在左侧“原文”区域粘贴或输入裁判文书文本。
3. 根据需要选择 **“替换式脱敏”** 或 **“遮蔽式脱敏”** 模式。
4. 勾选您希望脱敏的字段类别。
5. 点击 **“执行脱敏”**，右侧即显示脱敏结果，同时下方对照表会列出所有被替换的实体。
6. 可对对照表中的任一实体单独 **“取消替换/遮蔽”** 或 **“重新替换”**。
7. 点击 **“复制结果”** 可拷贝脱敏后的文本；点击 **“复制对照表”** 或 **“下载对照表 (CSV)”** 可导出替换关系。
8. 如需重新开始，点击 **“清空”** 即可。

## ⚠️ 注意事项

- 本工具基于正则表达式匹配，**不能保证 100% 覆盖所有敏感信息**，建议脱敏后人工复核。
- 部分字段（如“当事人姓名”）可能因文本格式差异而漏配，请结合对照表检查。
- 所有数据仅在您浏览器内存中运行，**不会上传至任何服务器**，请放心使用。
